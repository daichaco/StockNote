# App Store 掲載文(日本語)

App Store Connect の各欄に貼り付けられます。`〔 〕` は、あなたが決めて差し替える部分です。

## アプリ名(30文字まで)
- 第一候補: `のこりメモ`
- 使われていた場合の候補: `のこりメモ - 残量と期限の記録` / `のこりメモ 日用品・防災`

※ アプリ名は、他のアプリと重複できません。App Store Connect で作成するときに使えるか分かります。決まったら、アプリの表示名(`INFOPLIST_KEY_CFBundleDisplayName`)と Bundle ID も合わせます。

## サブタイトル(30文字まで)
`日用品・食品・防災の残量と期限`

## プロモーションテキスト(170文字まで。審査なしでいつでも変更可)
`「まだ大丈夫」のうちに切れてしまうのを防ぎます。残量はスライドで、気づいたときにさっと記録。購入日からの日数や、食品・防災用品の期限も、一覧で確認できます。`

## 説明文(4000文字まで)
```
のこりメモは、日用品や食品の「残り」と「期限」を、スライドで手軽に記録するアプリです。

【残量をスライドで記録】
洗剤、シャンプー、トイレットペーパー…。減ったなと気づいたときに、一覧の中でスライダーを動かすだけ。画面を開き直す必要はありません。
「買った」を押すと、残量が満タンに戻り、購入日が今日になります。

【「要確認」を先頭に強調】
残りわずかの品と、期限が近い・過ぎた品は、一覧の先頭にまとめて色つきで表示します。買い物リストを別に作らなくても、買うべきものが一目で分かります。

【購入日からの日数】
「購入から○日」を表示するので、どれくらいのペースで減っているかが見えてきます。

【期限の管理】
食品はもちろん、電池や常備薬など、期限のあるものは期限を登録できます。警告日の朝に通知でお知らせします。

【防災バッグの点検】
水、非常食、携帯トイレ、懐中電灯など、防災バッグの定番から選んでまとめて追加できます(一般的な備えの目安です)。期限、数量、最終点検日を管理して、「点検した」ボタンで記録します。

【その他】
・食品 / 日用品 / 防災バッグで切り替え
・用意されたカテゴリに加えて、自分のカテゴリも追加できます
・データは端末の中だけに保存します。アカウント登録は不要です

【広告について】
無料版では、一覧の下に広告が表示されます。「広告を消す」(買い切り)を購入すると、広告が表示されなくなります。無料版でも、機能の制限はありません。
```

## 審査メモ(App Review Information の「メモ」欄)
```
ログインは不要です。
日用品・食品・防災用品の残量と期限を記録するアプリです。データは端末内にだけ保存します。
動作確認の手順:
1. 右上の「＋」→「品目を追加」で品名を入れて「保存」します。
2. 一覧の行のスライダーを動かすと、残量が変わります。残りわずかになると、先頭の「要確認」に移ります。
3. 「＋」→「防災バッグの定番から追加」で、防災用品をまとめて追加できます。
4. 設定(左上の歯車)の「広告を消す」が、アプリ内課金(非消耗型)です。「購入を復元」もあります。
無料版では、一覧の下に Google AdMob のバナー広告が表示されます(パーソナライズなし)。
```
