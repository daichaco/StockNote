# 広告(Google AdMob)の設定手順

いまのアプリは、Google 公式の**テスト用 ID**で動いています。本番の広告を出すには、あなた自身の AdMob アカウントで ID を発行して、差し替えます。

| | 状態 |
|---|---|
| Debug ビルド(開発中) | テスト広告を表示(Google 公式のテスト ID) |
| Release ビルド(App Store 用) | **広告を出さない**(本番の広告ユニット ID が入るまで nil)。テスト ID のまま公開してしまうのを防ぐ安全策 |

## あなたがすること

1. **AdMob のアカウントを作る**: https://admob.google.com
   - Google アカウントでサインインし、利用規約に同意する。
   - お支払い情報(受け取り口座)、住所、税務情報は、AdMob の画面に**あなた自身が**入力する。Claude は入力しない。
2. **アプリを追加する**: AdMob →「アプリ」→「アプリを追加」→ iOS。
   - App Store 公開前でもよい(「まだ公開していない」を選ぶ)。
   - 発行される **アプリ ID**(`ca-app-pub-数字~数字`)を控える。
3. **広告ユニットを作る**: そのアプリ →「広告ユニット」→ バナー。
   - 名前は自由(例: `list-banner`)。発行される **広告ユニット ID**(`ca-app-pub-数字/数字`)を控える。
4. **2 つの ID を Claude に伝える**(ID は秘密の情報ではない。広告のたびに端末へ送られる値)。Claude が次の 2 か所を書き換える。
   - `Config/Info.plist` の `GADApplicationIdentifier`(アプリ ID)
   - `App/AdBannerView.swift` の `AdConfig.bannerUnitID` の Release 側(広告ユニット ID)

## 守ること

- 開発中に、**自分の本番広告をタップしない**。無効なクリックとして、AdMob のアカウントが止められることがある。Debug ビルドは必ずテスト ID を使う(いまの設定のまま)。
- EEA(EU など)・英国に配信するなら、Google の同意管理(UMP)の実装が必要。**日本だけに配信するなら不要**(App Store Connect の「価格と配信状況」で配信地域を選ぶ)。
- 広告はパーソナライズなし(`npa=1`)で出す。トラッキング許可(ATT)のダイアログは出さない。パーソナライズを使いたくなったら、ATT と同意管理の実装が必要になる。

## App Store Connect の「App のプライバシー」

このアプリは広告 SDK を使うので、数独ヘルパーのように「データを収集しない」を選べない。回答は、Google が公開している「AdMob 向けの Apple のデータ開示ガイド」に沿って選ぶ(SDK のバージョンで変わりうるため、提出の直前に最新版を確認する)。ここに書いてある内容(パーソナライズなし、ATT なし)が、回答の前提になる。

## 収益が増えるかもしれない任意の設定(後回しでよい)

- `Info.plist` に `SKAdNetworkItems`(Google が公開している ID の一覧)を入れる。広告主が成果を測れるようになり、単価に効くことがある。
- AdMob の「ブロックのコントロール」で、広告のカテゴリ(ギャンブルなど)を除外する。
